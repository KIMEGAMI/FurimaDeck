# FurimaDeck（フリマ販売の収益管理SaaS）

## 概要

FurimaDeck は、ヤフオク・メルカリ・Yahooフリマ・ラクマなどのフリマサービスで販売する商品の管理と収益確認を目的としたWebアプリケーションです。

出品商品の登録、編集、削除、売上管理、利益計算、CSVによる一括管理など、個人でフリマ販売を行う際に必要となる機能を実装しました。

## 工夫した点

### CSVインポート・エクスポート機能

大量の商品を効率良く管理できるように、CSVによる一括登録機能とCSV出力機能を実装しました。

CSVファイルの文字コード違い（UTF-8、Shift-JISなど）にも対応し、日本語環境でも問題なく利用できるよう工夫しています。

また、既に登録済みの商品については重複登録を防止する仕組みを実装し、実運用を意識した設計にしました。

---

### フリマアプリごとの手数料計算

ヤフオク、メルカリ、Yahooフリマ、ラクマなど各サービスごとに異なる販売手数料を自動計算できるようにしました。

送料も考慮した実利益を算出し、単純な売上だけでなく「実際にいくら利益が出たか」を把握できるようにしています。

---

### SOLD画像の自動生成

商品が売却された際に、GDライブラリを利用してSOLD画像を自動生成する機能を実装しました。

ユーザーが画像編集ソフトを利用しなくても、視覚的に売却済みであることが分かるようにしています。

## 苦労した点

### データベース設計による不具合の調査

開発中に管理IDの重複登録に関する不具合が発生しました。

当初の設計では問題ないと考えていましたが、実際にはデータベースの制約、Laravelのバリデーション、ユーザーごとのデータ管理など複数の要素が絡み合っており、原因の特定に時間がかかりました。

テーブル設計、インデックス、外部キー制約、認証処理を一つずつ確認しながら検証を進めることで解決しました。

この経験を通じて、実装だけでなくデータベース設計の重要性と、問題を切り分けながら調査する力を学ぶことができました。
