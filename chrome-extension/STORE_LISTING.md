FurimaDeckの商品編集画面から、商品ごとに出品先を選んで出品準備を進める拡張機能です。商品一覧を拡張popup内に表示せず、選んだ商品の情報を公式出品フォームの識別できる空欄へ入力します。フォーム送信や出品確定は行わず、入力結果を確認して足りない項目を補い、出品を確定するのは利用者です。

## Release blockers

- 2026-10-15に本番URL `https://furimadeck.kimegami.jp/api/extension/v1/me` を未認証で確認したところ404でした。現行の拡張API routesはローカル作業ツリーにはありますが、本番でまだ提供されていません。拡張API・DB migration・商品画面の出品先リンクを、既存ユーザーや会計機能に影響しない範囲で通常のリリース手順から本番へ適用し、未認証時に404ではなく認証応答が返ることを確認するまで提出しないでください。
- Chrome Web Store上でアイテムIDが確定した後、本番 `.env` の `FURIMADECK_CHROME_EXTENSION_ID` をその32文字IDに設定して設定キャッシュを更新し、CORSとPKCE連携を本番で検証してください。空欄の本番設定はfail-closedとなり、拡張連携できません。IDは公開識別子であり秘密値ではありません。

## Privacy practices

- 単一目的: FurimaDeck利用者が自分の商品情報を各フリマの出品準備へ再利用し、掲載履歴を管理できるようにする。対応4サイトでは明示的な任意権限の許可後に限り、登録済み情報と画像の入力を補助する。
- リモートコード: 使用しない。APIから取得するのは商品・掲載等のデータのみで、コードを取得・実行しない。
- プライバシーポリシー: 上記の本番URLを設定し、同ページに本拡張のデータ説明が公開されていることを先に確認する。
- データ区分候補（Dashboardの選択肢と照合）:
  - 個人情報: FurimaDeck APIが返すアカウント表示名
  - 認証情報: FurimaDeck APIアクセストークン（Chrome session storageに保持）
  - 財務・決済情報: 利用者が要求した売上CSVの内容（売上・利益額等）
  - ユーザー作成コンテンツ: FurimaDeck商品情報、商品画像、掲載情報、定型文
- ウェブサイトのコンテンツ／フォームデータ: 利用者が選択した出品フォームのラベル、入力欄属性、選択肢、現在値、画像欄の状態を端末内で一時的に確認する。サーバーへ送信・保存しない。
- ウェブ閲覧アクティビティ: FurimaDeck商品画面で利用者が選択した商品のID・出品先（セッション中のみ、最長10分）。選択サイトのホスト名・URLは入力先判定に端末内でのみ使い、送信・保存しない。閲覧履歴は収集しない。
- データ利用: アカウント連携、本人が要求したCSV取得、定型文管理、商品画面で選ばれた商品ドラフトの表示、利用者が許可したサイトへの入力補助。
- 第三者への販売、広告・プロファイリング目的の利用: なし。
- データ移転: 利用者が選択した出品先のフォームへ商品情報・画像を反映します。ページ側が入力イベントに応じて下書き保存や画像アップロード等を行う可能性があり、ログイン済み実画面でサイトごとの挙動は未検証です。拡張はフォーム送信・出品確定を行いませんが、サイト側の自動処理は制御しません。フリマのフォーム情報や閲覧先URLはFurimaDeckへ送信・保存しません。
- 同意: 商品API取得、閲覧中ホスト名の判定より前に、ポップアップまたは設定画面で収集・利用目的を表示し、明示的なチェックとボタン操作を求める。

## Permission justifications

- `storage`: 利用者が同意した状態、表示テーマ、セッション中の連携情報を保持するため。アクセストークンは `storage.session` に置き、永続設定には保存しない。
- `identity`: FurimaDeckとのPKCE形式の端末連携をChrome Identity APIで完了するため。
- `clipboardWrite`: 利用者が押したコピー操作で、選択された出品項目または定型文をクリップボードへ書き込むため。
- `activeTab`: 利用者が「現在のページを判定」または入力補助の再試行を押した時に、対象タブを確認・操作するため。
- `scripting`: FurimaDeck商品画面の出品先クリックを検知し、利用者が選択した場合に限って、許可済みサイトの公式フォームで入力補助を実行するため。閲覧ページ全体、履歴、Cookieは読み取らない。
- Optional host permissions（提出用ZIP）: FurimaDeck APIと接続・連携画面、および利用者が選択したサイトのフォーム入力に必要なホストだけ。`https://furimadeck.kimegami.jp/*`、`https://jp.mercari.com/*`、`https://fril.jp/*`、`https://paypayfleamarket-sec.yahoo.co.jp/*`、`https://auctions.yahoo.co.jp/*`。各サイト権限は拡張popupから個別に許可する。`http://127.0.0.1/*` は開発用ビルドにのみ含め、提出用ZIPから除外します。

## Reviewer test instructions

1. 拡張をインストールし、ポップアップを開く。
2. データの取り扱い説明とプライバシーポリシーへのリンクを確認する。同意しない場合、商品API通信とページ判定が行われない。
3. 審査用FurimaDeckアカウントで「アカウントを連携」を押し、開いたFurimaDeck承認画面で連携を許可する。
4. FurimaDeckの商品編集画面を開き、左側の「出品先」から各フリマをクリックする。公式出品画面が新しいタブで開く。
5. 商品一覧はpopupに表示されないことを確認する。任意権限を許可したサイトでは、テスト商品名・説明・価格・カテゴリ・状態・配送情報・画像が特定可能な空欄へ入力され、既入力値が維持され、フォーム送信されないことを確認する。
6. 設定画面で権限、操作履歴、プライバシーポリシー、端末解除を確認する。

審査用アカウントの発行や資格情報の提供が必要な場合は、Dashboardの審査用テスト手順で安全に管理してください。ログインパスワードや本番トークンをこのリポジトリへ記載してはいけません。
