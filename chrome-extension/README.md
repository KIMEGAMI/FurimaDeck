# FurimaDeck Chrome拡張（開発版）

Manifest V3の出品準備補助拡張です。商品は拡張popup内に一覧表示せず、FurimaDeckの商品編集画面にある出品先リンクから選ぶ導線です。popupは連携・設定・CSV・定型文・権限設定に使います。0.1.15では、利用者がサイトごとの任意アクセス権を許可し、FurimaDeckの商品編集画面から出品先を選んだ場合、メルカリ・ラクマ・Yahoo!フリマ・Yahoo!オークションの公式出品フォームに、登録済み情報と画像のうち一意に判定できた空欄を入力します。標準入力欄に加え、アクセシビリティラベルで一意に識別できる説明欄等にも対応します。手動コピーには登録済みの出品項目を日本語表示でまとめ、出品数量・配送情報・カテゴリ属性も含めます。入力欄のラベル・属性・選択肢・現在値は空欄の判定のため端末内で一時確認し、フリマには商品情報・画像を渡します。画像の転送上限を超える場合は、全枚数と転送枚数を画面に表示し残りを手動追加できるよう案内します。サイト側の仕様で下書き保存・画像アップロードが起きる可能性がありますが、その挙動は未検証です。拡張はフォーム送信・出品確定を行いませんが、サイト側の処理は制御しません。既入力・曖昧・一致しない選択肢は変更せず、各社の許可を得た機能ではなく規約リスクは未解決です。同意が解除された状態では商品ID等を保持せず、公式出品ページを開くだけです。

初回利用時に、商品・売上・認証情報・ページ判定で扱うデータの説明を表示し、チェック操作で同意するまでAPI通信やページ判定を行いません。利用者データは開示した単一目的の機能提供に限って扱います。詳細は公開プライバシーポリシーを参照してください。

## ビルドとローカル読み込み

1. リポジトリのルートで依存関係をインストール済みであることを確認します（拡張用の追加依存はありません）。
2. `chrome-extension` ディレクトリで `npm run build` を実行します。
3. Chromeの `chrome://extensions` を開き、デベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」から `chrome-extension/dist` を選びます。
4. 拡張を開き、ローカルFurimaDeck URLを指定して「アカウントを連携」を押し、ログイン済みのFurimaDeck画面で端末連携を承認します。
5. 拡張popupの「各出品先の入力権限を許可」から使うサイトだけ任意権限を許可した後、商品編集画面の左側で出品先を選びます。出品フォームの空欄で一意に判定できた商品名・説明・価格・カテゴリ・状態・配送情報・画像を入力します。登録値とサイト選択肢が一致しない場合は手動入力してください。利用者が内容を確認し、出品操作を行います。

`npm run test:chrome` はPlaywrightが一時プロファイルのChromeを起動し、Chrome DevTools Protocolで `dist` を読み込みます。商品画面リンクからドラフトAPI・新しいタブ・実際のフォーム入力関数までを、APIとタブだけモックした合成Mercariフォームで一続きに検証します。4サイトの合成フォームに対する項目マッピング・画像転送、既入力値・曖昧欄・非出品画面の不変更、送信操作なしも確認します。`npm run test:package` は提出用ZIPのmanifestと必須ファイルを確認し、開発用distに対してChrome E2Eを実行します。ログイン後の実フォーム互換性、各社の許可、実アカウントでの動作は未確認です。実アカウントや通常プロフィールには接続せず、既存ブラウザーデータにも触れません。実サイトの確認項目は [`MANUAL_FORM_TEST.md`](MANUAL_FORM_TEST.md) を参照してください。

## Chrome Web Store 公開準備

- `STORE_LISTING.md` に、掲載タイトル・要約・説明文、単一目的、権限理由、データ開示の入力案、審査担当者向けテスト手順をまとめています。ダッシュボードのプライバシー申告はこの内容と実装・公開ポリシーを一致させてください。
- `npm run package:store` はビルド済み `dist` を一時ステージングし、開発専用の `http://127.0.0.1/*` 権限を除外し、接続先の初期値を本番URLに置き換えてから、manifestをZIP直下に置いた提出用ZIPへまとめます。ローカル開発用 `dist` 自体は変更しません。生成先は `release` です。
- `npm run test:package` はmanifestのバージョンと一致するZIPを一時展開し、開発ホスト権限がZIPに含まれないことと必須ファイルを確認します。その後、ローカル開発用 `dist` をChromeでE2Eテストします。
- 0.1.15の入力補助は任意アクセス権の許可後に商品編集画面から利用者が出品先を選択した場合のみ動作します。規約上の許可は未確認です。ラクマは公式サポートからツール入力を控えるよう案内されています。入力イベントでサイト側の自動保存・画像送信が行われる可能性は未検証です。Chrome Web Storeへ提出・公開する前に、各社規約・ストア審査要件を確認し、ログイン後の実フォームで項目対応をテストしてください。拡張自体はフォーム送信・出品確定を実装していません。

## 権限と扱うデータ

- 必須権限は `storage`、`identity`、`clipboardWrite`、`activeTab`、`scripting` です。
- 接続先ホスト権限はオプション扱いで、本番FurimaDeck、`127.0.0.1`、および利用者が個別許可する4サイトの出品画面のみです。全サイト権限は要求しません。
- manifestの自動 `content_scripts` は登録していません。FurimaDeckと連携後、商品画面の出品先クリックを検知する小さなスクリプトだけをFurimaDeckオリジンに動的登録します。各サイトの入力処理はそれぞれの任意権限を許可した場合に限ります。
- アクセストークンは `chrome.storage.session` に保持し、アカウント連携の解除・ブラウザーセッション終了で消去します。ソースコードや診断情報に認証情報を含めません。
- 商品情報・画像はFurimaDeck APIから本人所有の商品だけ取得します。利用者が選んだ出品先に対応する画面上に入力し、そのサイト内だけで表示します。拡張はプラットフォームのサーバーへのフォーム送信や出品確定をしません。

FurimaDeckアカウントの連携は10分で失効するワンタイム承認コードを使います。交換後の限定スコープBearer tokenはChromeのセッションストレージにだけ置き、有効期間は7日です。FurimaDeckの `/chrome-extension/devices` から失効できます。接続先は本番FurimaDeckまたは `127.0.0.1` の開発環境に限定しています。

設定画面では、接続権限・対応サイト・操作履歴・テーマを確認できます。診断情報のコピーには拡張のバージョン、接続状態、API応答状態、権限の有無だけを含め、認証トークン、アカウント名、商品情報、接続先URLは含めません。操作履歴APIも本人の拡張操作について、操作名と日時だけを返します。

## 現在のサイト操作レベル

拡張popup内に全商品リストを表示しません。メルカリ・ラクマ・Yahoo!フリマ・Yahoo!オークションは、出品先ごとの任意ホスト権限が許可され、FurimaDeck商品画面で利用者が選んだ場合に限り、登録済みの商品データを一意に判定できた空欄へ入力します。既入力欄、曖昧欄、カテゴリ等の一致しない選択肢は変更しません。フォーム送信、出品登録、メッセージ送信は行いません。各社の許可と実フォーム互換性は未確認です。ラクマは公式サポートからツール入力を控えるよう案内されています。メルカリShopsは入力補助対象外です。

商品ドラフトは選択した出品先に対応する既存の掲載情報（タイトル・説明・価格・カテゴリ・状態・配送設定）を優先します。カテゴリ・状態・配送設定はサイトの選択肢と完全一致した場合だけ入力し、推測で値を補いません。画像は10枚・合計5 MiBまでを試作上限とし、それを超える場合は手動で追加してください。自動送信・自動出品は無効です。

サイトごとの公式ルール、問い合わせ状況、入力補助のリリース条件は [`PLATFORM_CAPABILITY_REVIEW.md`](PLATFORM_CAPABILITY_REVIEW.md) を参照してください。

## 出品先の緊急停止

Laravel側でサイトごとに停止できます。対象環境の `.env` で該当値を `false` に設定し、設定キャッシュを更新してください。停止中は、そのサイトのドラフト取得と掲載履歴書き込みをAPI側で拒否します（商品検索や他サイトには影響しません）。

- `FURIMADECK_EXTENSION_PLATFORM_MERCARI_ENABLED`
- `FURIMADECK_EXTENSION_PLATFORM_RAKUMA_ENABLED`
- `FURIMADECK_EXTENSION_PLATFORM_YAHOO_FLEA_MARKET_ENABLED`
- `FURIMADECK_EXTENSION_PLATFORM_YAHOO_AUCTIONS_ENABLED`
- `FURIMADECK_EXTENSION_PLATFORM_MERCARI_SHOPS_ENABLED`

`.env` の変更を反映するには、対象環境でLaravelの設定キャッシュをクリアして再生成してください。値が未設定の場合は各出品先の手動補助が有効です。自動出品・自動送信は無効です。

## トラブルシューティング

- 拡張が一覧に出ない／古いコードのまま: `chrome-extension` で `npm run build` を実行し、`chrome://extensions` の対象拡張で再読み込みします。読み込むフォルダーはリポジトリ直下ではなく `chrome-extension/dist` です。
- `127.0.0.1` に接続できない: FurimaDeck開発サーバーとDBが起動していることをブラウザーで確認し、接続時に表示されるローカルホスト権限を許可します。APIキーや本番シークレットを設定する必要はありません。
- APIが401／連携期限切れ: 設定画面またはFurimaDeckの拡張端末管理から端末を解除し、拡張で再連携します。連携コードは10分、アクセストークンは7日で失効します。
- ドラフトに価格・カテゴリ・配送情報がない: FurimaDeckの商品に加えて、対象出品先の掲載情報を登録してください。未設定の情報は拡張が推測せず「要確認」にします。
- 特定出品先のAPIが503: サーバー側の出品先停止スイッチを確認します。停止スイッチはドラフト取得と掲載記録を拒否します。
- CSVや画像を保存できない: Chromeのダウンロード設定・保存先の確認後、拡張画面からもう一度操作してください。画像は商品ごとに「画像保存」を押した時だけダウンロードします。

## API

- `POST /api/extension/v1/pairing/start`
- `POST /api/extension/v1/pairing/complete`
- `POST /api/extension/v1/pairing/revoke`
- `GET /api/extension/v1/me`
- `GET /api/extension/v1/activity`
- `GET /api/extension/v1/products`
- `GET /api/extension/v1/products/{id}/draft?platform=...`
- `GET /api/extension/v1/products/{id}/images/{imageId}`
- `POST /api/extension/v1/products/{id}/listing-records` — 利用者が実掲載を確認したURL・価格のみ登録
- `GET /api/extension/v1/templates`
- `POST /api/extension/v1/templates`
- `PATCH /api/extension/v1/templates/{id}`
- `DELETE /api/extension/v1/templates/{id}`
- `GET /api/extension/v1/exports/products.csv`
- `GET /api/extension/v1/exports/listings.csv`
- `GET /api/extension/v1/exports/sales.csv`

商品CSVの取込は既存のFurimaDeckプレビュー画面を開き、文字コード・列・行エラーを確認してから確定します。拡張は既存商品の一括更新や、確認なしの取込確定を行いません。

商品APIは連携ユーザーの所有商品に限定され、ページ件数・入力長・レート制限を適用します。トークン原文はDBに保存せず、商品本文やトークンを監査ログに含めません。
