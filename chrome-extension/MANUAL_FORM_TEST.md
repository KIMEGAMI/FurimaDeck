# 実フリマ出品フォーム確認（0.1.15）

目的は、合成フォームでは確認できない実画面の項目対応と、入力イベントを受けたサイト側の動作を記録することです。自動テストでは商品リンクから合成フォームへの全経路を検証しますが、各サイトのログイン済み実フォームやサイト側の下書き保存・画像アップロード挙動までは確認できません。この実操作で実サイトの動作を確かめます。出品を公開・確定するテストではありません。

## 実施前

1. Chrome拡張を `chrome://extensions` で再読み込みし、版が `0.1.15` であることを確認します。
2. テスト用商品を使い、商品名・説明・価格・配送情報・カテゴリ属性・画像を事前に確認します。実在人物の情報や公開したくない画像は使わないでください。
3. 初回のデータ取扱い同意を読み、選択したサイトのページへ商品情報・画像が渡ること、ページ側が入力時に下書き保存や画像アップロードを行う可能性があり挙動未検証であることを確認します。
4. 商品編集画面の「出品先」から対象サイトを選びます。権限要求が出たら対象サイトだけ許可します。ログイン要求が出た場合は本人が判断し、資格情報をチャットやテストログに貼らないでください。

## 1サイトごとの記録

| 確認項目 | 結果 |
| --- | --- |
| 出品先リンクから正しい出品ページが新しいタブで開いた | 未確認 |
| 商品名・説明・価格が正しい値で入った | 未確認 |
| カテゴリ・商品状態が正しく入った／未入力の理由 | 未確認 |
| 配送方法・送料・送料負担・発送元・日数が正しく入った／未入力の理由 | 未確認 |
| 商品属性（ブランド・サイズ等）・コード・型番が正しく入った／未入力の理由 | 未確認 |
| 画像の枚数・順序・内容が正しい | 未確認 |
| 入力済み欄が上書きされなかった | 未確認 |
| 入力イベント直後に下書き保存・画像アップロード等が起きたか | 未確認 |
| 出品確定操作をしていない | 未確認 |
| 拡張に表示された完了／未入力／曖昧欄のメッセージ | 未確認 |

サイトが想定外に商品を公開した、または公開状態になった疑いがある場合は、その場で追加操作を止め、サイトの公式画面で状態を確認してください。下書き保存や画像アップロードだけでもサイトへデータが渡っている可能性があります。

## 対応先と注意

- Yahoo!フリマ: [出品ページ](https://paypayfleamarket-sec.yahoo.co.jp/item/add?from=sellTop)。サポートは個別機能の規約判断を行わないと回答しています。許可確認済みとは扱いません。
- Yahoo!オークション: [出品ページ](https://auctions.yahoo.co.jp/sell/jp/show/submit?category=0)。Yahoo!フリマの回答をYahoo!オークションの許可とみなしません。
- ラクマ: [出品ページ](https://fril.jp/item/new)。公式サポートは、最終確定を利用者が行う場合でもツール入力を控えるよう案内しています。試験はこの警告とアカウントリスクを理解した場合に限ります。
- メルカリ: [出品ページ](https://jp.mercari.com/sell/create)。第三者拡張による入力の可否は未確認です。利用可能な本人のテスト環境がなければ試験しないでください。

## 報告フォーマット

`サイト名 / 正しく入った項目 / 入らなかった項目と画面表示 / 画像の状態 / 入力時の下書き保存・アップロードの有無 / 出品確定していないこと`

アカウント名、商品画像、住所、電話番号、ログイン情報、URL内の認証コードは共有しないでください。必要なら個人情報を隠した画面だけ共有してください。
